# Euthyphro Spatial Memory PoC

Current active version: **7.1**

Public entry point: `index.html`

## Active structure

- `index.html` — canonical public entry for Version 7.1.
- `preview-development-notes/` — current Version 7.1 application files. Despite the legacy folder name, this is the active build.
- `preview-interactive/` — interactive reconstruction module embedded within Version 7.1.
- `preview-v2/` — retained shared reconstruction imagery and ancient Agora map assets required by the active build.
- `styles.css`, `refinements.css`, `text-data.js` — shared active assets used by Version 7.1.

## Archived history

Earlier working states are preserved as Git branches rather than kept as duplicate live folders:

- `archive/v6.1-stable`
- `archive/v7.0-before-7.1`
- `archive/pre-cleanup-7.1`
- `release/v7`
- `release/v7.1`

The `main` branch should contain only files required by the current Version 7.1 build and its live reconstruction assets.
